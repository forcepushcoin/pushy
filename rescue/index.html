// How it works

The same scan as Pushy Score, plus a fix for each finding.

1. Scan

Reads the repo with the public GitHub API (about 4 calls) and runs the Pushy Score rules in your browser. Your real score comes out of that step and is never changed.

2. Fix

Line edits where a rule can make one safely (swap a secret for an env var, pin a force-push, strip hidden characters). Everything else becomes a checklist step. Files that were not fully fetched or have mixed line endings get no patch.

3. Re-scan

Rescue runs the same rules on the patched files. The result is a projected score, a what-if, and it counts every edit as done. Download the .patch, read it, apply it with git apply.

Suggestions, not guarantees · Basic tools are free and never need the token

Pushy Rescue is not affiliated with GitHub or any repo owner. Only public data is read, nothing is stored on a server. Paying with the token never changes a score. $FORCEPUSH is a meme coin, NFA.
