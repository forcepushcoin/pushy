// How it works

GitHub issues are the database. No server, no accounts.

1. Submit

Open an issue with the Bounty template. It gets the bounty label and shows up here as proposed. A Reward: 500 USDC line in the issue is shown as "as written by author".

2. Review

A maintainer labels it bounty-accepted (shown as open), bounty-claimed or bounty-paid. A reward: 500 USDC label is a confirmed amount, because only maintainers can set labels.

3. Payout

Planned at launch in $FORCEPUSH from the public pool wallet, with an address you give on the issue. Nothing is payable until the wallet is published. Full rules in BOUNTIES.md.

No payout is guaranteed · Basic tools are free and never need the token

The bounty board is not affiliated with GitHub. Only public issue data is read, nothing is stored on a server. $FORCEPUSH is a meme coin: its value can go to zero, and nothing here promises a return. NFA.
